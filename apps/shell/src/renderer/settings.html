MODEL CONNECTION / OPENROUTER

Connect your model

Use one OpenRouter key for chat and agent tasks. MARS uses it to sign in to OpenRouter, not as part of your prompts.

1. Create your key

Visit openrouter.ai/settings/keys, choose Create API key, and copy it.

Stored in your system’s secure storage when available; otherwise used only until MARS quits. Saving checks the format only. Removing a key from MARS does not revoke it at OpenRouter.

Chat uses OpenRouter’s free route. Agent tasks use the host’s default model unless you explicitly choose a paid one.
