MODEL CONNECTION / OPENROUTER

Connect your model

Use one OpenRouter key for chat and agent tasks. MARS uses it to sign in to OpenRouter, not as part of your prompts.

1. Create your key

Sign in to OpenRouter, choose Create API key, and copy it.

Stored in your system’s secure storage when available; otherwise used only until MARS quits. Updating the key reconnects your workspace.

Chat uses OpenRouter’s free route. Agent tasks use the host’s default model unless you explicitly choose a paid one.
