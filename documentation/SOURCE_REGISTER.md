## Interpretation

`audit_checks` and `acceptance_plan` are historical source-audit observations/plans. A proposed acceptance plan is not a passed test. Current MARS checks are recorded separately in the milestone report. A test performed in an upstream audit fixture is not a test of this integrated platform.

The master specification remains unchanged, with its original 32 planning references. The manifest replaces mutable implementation references with commit-specific license and module URLs. Papers and explanatory articles in the specification are background references, not executable dependencies.

Oh My Pi is the only installed component from this audit, using two exact artifacts and locked transitive dependencies. No Python worker is installed into this Bun workspace. watch-skill is an external Python runtime (pip `watch-skill==1.4.3`) that the `@mars/watch` host runs as a subprocess; it is not installed into the workspace either. In particular, DSPy and GEPA HEAD pins describe separate audited components, **not a compatible combined installation**: DSPy pins GEPA 0.1.4, whereas the audited GEPA HEAD differs. Resolve a common revision or use a separately versioned direct GEPA worker before Milestone 4.

Milestone 4 adds `terminal-bench-2` as a consumed dataset, not a vendored source: Harbor fetches the pinned task commit at run time, the candidate agent only receives `instruction.md`, and verifier files never enter this repository. The task repository carries no license file at the pinned commit, so no redistribution right is asserted; results stored by `@mars/evaluation` are task names, commit ids, rewards, costs and MARS-produced trajectories. Harbor, mini-swe-agent and GEPA run in a separate pinned Python 3.12 virtual environment launched and bounded by the Bun side (`harbor==0.25.0`, `mini-swe-agent==2.4.6`, `gepa==0.1.4`); DSPy is not installed, because DSPy 3.4.1 pins GEPA 0.1.4 while the audited GEPA HEAD differs.

No upstream source is vendored wholesale. Attributed TypeScript ports/adaptations exist in `packages/context` (Aider), `packages/memory/src/threats.ts` (Hermes), `packages/skills` and `packages/review` (OpenClaw, Hermes), each with a `NOTICE` and the upstream license text under `third_party/`. The only verbatim upstream files are the ten `skills/*/SKILL.md` files of watch-skill v1.4.3, copied byte-identical under [`skills/vendor/watch-skill/`](../skills/vendor/watch-skill/) together with the upstream MIT `LICENSE` and a `NOTICE.md` recording repository, revision and version; they are untrusted skill content for the skill service, not platform instructions. Do not copy Cline UI, DGM benchmark data, model weights, or datasets without preserving their specific notices and completing the corresponding license review. Bundled native/npm notices remain part of their installed artifacts; inspect `LICENSE` and `THIRD-PARTY-NOTICES.txt` in the installed packages before redistribution.
